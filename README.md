# GT-Funny-Idea · 邪门想法

邪门想法（GT-Funny-Idea）是为 GTNH 1.7.10 制作的扭曲玩法模组。模组 ID 为 `gtfi`，当前版本为 `0.1.2`。

[下载 v0.1.2](https://github.com/MIAOKATZE/GT-Funny-Idea/releases/tag/v0.1.2) · [使用与配方](#方块扭曲人弹射器) · [安全模式](#安全模式)

用神秘时代 4 的扭曲做些有趣的事：

- **扭曲人弹射器**：放置后检测附近玩家的扭曲，倒计时结束时将其弹飞。
- **便携扭曲人弹射器**：可装入 Baubles 吊坠槽，随持有者移动。
- **扭曲转移器**：通过法杖转换取得，将扭曲传给瞄准的玩家，并通过转移升级。

![扭曲人弹射器蓄力提示](docs/images/ejector-charging.png)

*蓄力图由用户提供：满足条件的玩家会看到统一警告与倒计时。*

## 安装环境

下载普通 `gtfi-v0.1.2.jar`，放入服务端和客户端的 `mods` 文件夹，两端使用相同版本。

开发基线为 GTNH `2.9.0-RC-2`，依赖 GregTech `5.09.54.205`、Thaumcraft `4.2.3.5`、ModularUI2 `2.3.92-1.7.10` 和 Baubles Expanded `2.2.25`。界面自带由 GTMB 移植的 pocket 主题资源，运行时不依赖 GTMB。`mcmod.info` 的版本字符串由 `RELEASE_VERSION` 加 `v` 前缀生成，例如 `v0.1.2`，不依赖 dirty Git describe。

## 方块扭曲人弹射器

游戏内名称为“扭曲人弹射器”。在工作台合成，放置后右键打开设置。

扭曲人弹射器配方：`E` 为 LV 发射器，`C` 为任意 LV 电路（矿辞 `circuitBasic`），`T` 为神秘锭块（矿辞 `blockThaumium`）。方块硬度为 `50`。

```text
E C E
C T C
E C E
```

输入数值后按回车或移开输入框焦点应用；服务端验证所有修改。

| 设置 | 范围与默认值 |
|---|---|
| 触发扭曲阈值 | 最低及默认均为 `25`；三类扭曲总量大于或等于阈值时触发 |
| 弹射力度 | `0.01–1000`，默认 `1` |
| 撞击伤害比例 | `0–100%`，默认 `100%` |
| 倒计时 | 普通模式至少 `15` 秒、默认 `20` 秒；安全模式可设为 `5` 秒 |
| 作用范围 | `10–200` 格，默认 `50` 格 |
| 开关 | 默认开启 |

临时、一般、永久三类扭曲之和达到或超过设置阈值后进入倒计时；默认阈值为 `25`，因此总扭曲达到 `25` 即可触发。有“扭曲结界”（Warp Ward）效果时不会触发。方块版作用范围内所有玩家均参与判定，包括设备持有者、放置者与创造模式玩家。

近距离基础速度为原始基础值的 `2` 倍，即 `100 × 力度 m/s`。方块力度 `0.01` 对应 `1 m/s`，力度 `1` 对应 `100 m/s`，力度上限 `1000` 对应 `100000 m/s`；便携力度 `0.001–1` 对应 `0.1–100 m/s`。

距离衰减系数为 `max(0.5, 1 - distance / range)`，从作用范围一半到边界保持 `50%`，范围外不触发。例如 `R=50`、力度 `1` 时，距离 `25–50` 格速度为 `50 m/s`。方块最低力度的外半程速度为 `0.5 m/s`，便携最低力度的外半程速度为 `0.05 m/s`。

金色粒子持续环绕方块节点旋转。撞击伤害为碰撞瞬间速度（`m/s`）乘以伤害比例，伤害穿甲并可伤害创造模式玩家。每次弹射后，玩家对所有弹射源共享 `5` 秒冷却。

飞行受到重力和阻力影响；到达尚未加载的区块边界时停止。

弹射源每服务端 tick 更新，离开有效范围、关闭或移走设备会使对应倒计时失效。方块版与便携版均在 HUD 显示“扭曲人弹射器正在蓄力中！”及倒计时；多个设备同时作用时，只显示最快结束的那个，剩余不足 `3` 秒时数字变红。

默认任何玩家都可修改方块数值和开关。开启安全模式后，只允许方块放置者或拥有二级命令权限的管理员修改；方块倒计时最短可设为 `5` 秒。

## 便携吊坠

游戏内名称为“便携扭曲人弹射器”，形态为吊坠。将一个凡人吊坠与一个扭曲人弹射器无序合成；凡人吊坠为神秘时代原版的 `ItemBaubleBlanks:0`。

放在普通背包或 Baubles 吊坠栏内均可生效。手持时右键打开设置，潜行右键切换开关。安全模式下，吊坠持有者仍可配置和开关。

| 设置 | 范围与默认值 |
|---|---|
| 触发扭曲阈值 | 最低及默认均为 `25`；三类扭曲总量大于或等于阈值时触发 |
| 弹射力度 | `0.001–1`，默认 `1` |
| 撞击伤害比例 | `0–100%`，默认 `100%` |
| 倒计时 | 至少 `5` 秒，默认 `5` 秒 |
| 作用范围 | `5–50` 格，默认 `10` 格 |
| 开关 | 默认开启 |

输入数值后按回车或移开输入框焦点应用。吊坠与方块使用相同的服务端扭曲判定、倒计时和距离衰减逻辑，随持有者移动更新作用中心。吊坠倒计时最短保留为 `5` 秒，近距离速度为 `0.1–100 m/s`。持有者本人免疫，无论吊坠在普通背包或 Baubles 吊坠栏中生效。

便携扭曲人弹射器支持 Baubles Expanded 的 `AMULET` 吊坠槽，并保留旧 `AMULET` 类型声明。多个吊坠按真实装备槽独立生效，卸下其中一个不会清除其他吊坠的弹射来源。

## 扭曲转移器

用神秘时代法杖右击扭曲人弹射器，将方块转换为转移器。转换会消耗方块，使用神秘时代原版的特殊物品实体、闪光效果和法杖音效生成转移器。开启安全模式时，禁止转换并保留原方块，现有转移器也不能使用。

非 Alt 转移时，须持续按住右键并瞄准同维度三格内、视线无遮挡的存活玩家满 `3` 秒后才开始转移。瞄准丢失会取消蓄力；更换目标后须重新蓄满 `3` 秒。开始转移后每秒最多转移“自身等级”点；松开右键后重新蓄力。潜行右键打开界面，查看自己的等级、经验并选择类型。

| 自身减少的类型 | 目标增加的类型 | 解锁等级 | 每转移一点获得经验 |
|---|---|---|---|
| 临时扭曲 | 一般扭曲 | 初始可用 | `1` |
| 一般扭曲 | 永久扭曲 | `3` 级 | `5` |
| 永久扭曲 | 永久扭曲 | `6` 级 | `20` |

等级与经验属于玩家，死亡后保留；转移类型选择保存在设备内。最高 `10` 级，九次升级所需经验依次为 `50、100、200、300、500、1000、2000、3000、5000`。达到 `3、6、10` 级会向全服通报。

按住 Alt 与右键可持续积累临时扭曲，每秒增长量为自身永久扭曲的 `1%`，不足一点的部分会累计。该自充操作不会消耗永久扭曲，也不受转移目标条件限制。

## 物品 Tooltip

方块、转移器和便携扭曲人弹射器这三件物品的 Tooltip 采用 GTSWN 的状态、描述、操作分区样式；末行以分段炫彩显示“添加模组：GT-Funny-Idea”。

## 安全模式

配置文件为 `config/gtfi.cfg`，`general.safeMode` 默认 `false`，修改后重启生效。

- 关闭时，任何玩家都可以修改方块弹射器的数值和开关。
- 开启时，只有方块放置者或拥有二级命令权限的管理员可以修改方块弹射器的数值和开关。
- 开启时，方块倒计时最短可设为 `5` 秒。
- 开启时，禁止通过法杖转换出转移器，现有转移器也不能使用。
- 吊坠由持有者控制，安全模式不额外限制其配置权限。

## 构建与测试

在 Windows PowerShell 中运行：

```powershell
.\gradlew.bat build
```

独立测试维度默认启用，ID 为 `22970`，可在配置文件的 `testDimension` 分类调整。管理员或控制台可依次执行 `/gtfi test build`、`/gtfi test run all`，通过 `/gtfi test status` 和 `/gtfi test report` 查看运行状态与报告；玩家可用 `/gtfi test enter`、`/gtfi test leave` 进入或离开。

本轮尚未进行游戏内验收；命令存在不代表已执行或已通过，界面显示、实际按键和动画仍须以真人客户端验收为准。工作区内另有 `plan/` 存放本地验证记录，该目录为独立记录仓库，不是主仓库发布文件。

本模组提供中英文物品名称、设置界面、提示与 HUD 文案。
